## The Problem: The "Desk-Tethered" AI Gap

Modern agentic AI coding assistants (such as Google Antigravity, Cursor, and Claude Code) operate locally inside rich IDE workspaces. However, developers are frequently away from their desks—walking, commuting, or reviewing physical documents—creating an operational disconnect:

1. **Information Asymmetry:** Photos of book pages, physical receipts, signatures, or quick mobile notes cannot easily reach the local AI context without manual upload rituals.
2. **Missing Out-of-Office Execution:** You cannot trigger terminal tasks, compile presentations, generate documents, or query the assistant while away from your keyboard.
3. **Delivery Failures:** Large binary files generated by the AI often fail to reach mobile devices without complex server infrastructure.

**Antigravity Cloud Bridge** solves this by establishing an autonomous, cloud-buffered, two-way bridge between your personal Telegram bot, the Resend email infrastructure, and your local AI workspace.

## Core Capabilities

### 1. Dual-Urgency Protocol (`- now` vs. Passive Buffering)

- **Passive Buffering:** Any photo, voice note, PDF, or text sent without `- now` is quietly saved into the `./inbox/` directory, appended to `mobile_notes.md`, and marked `BUFFERED` in the ledger without interrupting ongoing workflows.
- **Immediate Execution (`- now`):** Appending `- now` to any caption or message triggers instantaneous execution. The daemon acknowledges receipt within 3 seconds, runs autonomous LLM inference, compiles requested documents, and dispatches the output back to your Telegram chat.

### 2. Autonomous Document & Media Sanitizer

Automates document preprocessing and media optimization:

- **Signatures & Hand-Drawn Diagrams:** Crops tightly to ink stroke bounding boxes with a 5% margin, neutralizes shadows and paper texture to pure `#FFFFFF`, enforces $\le 600 \times 600\text{ px}$ and $< 100\text{ KB}$.
- **Profile & ID Photos:** Standardizes to a clean 3:4 aspect ratio, centered crop, neutral light background, and $< 200\text{ KB}$.
- **Large PDF Optimization:** Uses PyMuPDF stream deflation and intelligent DPI downsampling to ensure PDFs stay strictly under **1 MB (1,048,576 bytes)** while keeping charts, diagrams, and typography 100% legible.

### 3. On-the-Fly Office & Web App Compiler

Send a message from your phone like _"Create a 3-slide PPT on Distributed Systems Architecture - now"_ or _"Create a doc file on API Design Guidelines - now"_, and the engine autonomously compiles and delivers:

- **Microsoft Word (`.docx`):** Built via `python-docx` with styled hierarchy, executive color palettes, and bullet structures.
- **PowerPoint (`.pptx`):** Built via `python-pptx` with 16:9 widescreen slides, bold title cards, and high-impact layout.
- **Excel (`.xlsx`):** Built via `openpyxl` with colored header bands and auto-fit column dimensions.
- **Vector PDF (`.pdf`):** Built via `pymupdf` with styled CSS box rendering.
- **Standalone Web Apps (`.html`):** Compiles single-file, interactive HTML5/CSS3/JavaScript Progressive Web Apps that open and run directly in any mobile or desktop browser.

### 4. Context-Aware Dynamic Email Dispatcher (Resend API)

When emailing documents or summaries, the system dynamically maps sender identities to the active topic:

- **CI/CD & DevOps:** `DevOps Pipelines <ci@yourdomain.com>`
- **Code Reviews:** `Pull Request Reviews <reviews@yourdomain.com>`
- **Production & Incident Alerts:** `System Alerts <alerts@yourdomain.com>`
- **Sprint & Project Tracking:** `Sprint Updates <sprint@yourdomain.com>`
- **General Notifications:** `AI Assistant <assistant@yourdomain.com>`

If Telegram upload ever encounters file size limits or transient network errors, the dispatcher automatically routes the output to your email inbox without data loss.

### 5. Multi-Provider LLM Resolver

Incorporates resilient multi-provider failover:

1. **Primary:** OpenAI (`gpt-4o-mini`) for sub-second, highly structured responses.
2. **Secondary:** Google Gemini (`gemini-3.8-flash` / `gemini-flash-latest`).
3. **Tertiary:** OpenRouter free-tier endpoints.

### 6. Idempotent Monotonic Ledger

All ingested items are tracked by unique Telegram `update_id` in `inbox_ledger.json`. This eliminates duplicate downloads, prevents infinite loop triggers, and maintains an unalterable history of processed items.

## Quickstart & Installation

### 1. Clone & Install Dependencies

```bash
git clone https://github.com/rajchhapariya/antigravity-cloud-bridge.git
cd antigravity-cloud-bridge

# Create and activate virtual environment
python -m venv .venv
source .venv/bin/activate  # On Windows: .venv\Scripts\activate

# Install required dependencies
pip install -r requirements.txt

# (Optional) Install in editable mode for the CLI command
pip install -e .
```

### 2. Configure Environment Variables

Copy `.env.example` to `.env` and fill in your credentials:

```bash
cp .env.example .env
```

```env
# Telegram Bot Configuration
TELEGRAM_BOT_TOKEN=your_bot_token_here
TELEGRAM_CHAT_ID=your_chat_id_here

# Resend API Configuration
RESEND_API_KEY=re_your_api_key_here
NOTIFICATION_EMAIL_RECIPIENT=your_email@gmail.com

# LLM Providers (At least one is required)
OPENAI_API_KEY=sk-proj-...
GEMINI_API_KEY=AIzaSy...
OPENROUTER_API_KEY=sk-or-v1-...
```

## How to Get Your Credentials

### Telegram Bot Token & Chat ID

1. Open Telegram, search for `@BotFather`, and send `/newbot`.
2. Follow prompts to name your bot and receive your `TELEGRAM_BOT_TOKEN`.
3. Start a chat with your new bot by pressing **Start**.
4. To find your numeric `TELEGRAM_CHAT_ID`, search for `@userinfobot` on Telegram and send `/start`.

### Resend API Key

1. Sign up at [Resend.com](https://resend.com/).
2. Create an API key under **API Keys** with sending permissions.
3. Verify your domain or use their test domain.

## Usage Guide

### Running as a Background Daemon

Run the daemon continuously to poll for incoming mobile messages and dispatch files in real time:

```bash
python -m antigravity_bridge.cli --daemon --interval 3
```

### Single-Shot Sync

Fetch any unread items currently waiting in the Telegram cloud queue and exit:

```bash
python -m antigravity_bridge.cli --sync
```

### Sending Messages & Files Programmatically

```bash
# Send text message to your phone
python -m antigravity_bridge.cli --send-text "Training run completed with 98.4% accuracy."

# Dispatch a generated document to your phone
python -m antigravity_bridge.cli --send-file ./reports/briefing.pdf --caption "Executive Briefing"

# Dispatch an email via Resend
python -m antigravity_bridge.cli --send-email "Weekly Report" "Here is the summary of this week's progress."
```

### Media Sanitization CLI

```bash
# Sanitize signature to pure white background under 100KB
python -m antigravity_bridge.cli --sanitize-sig ./docs/raw_signature.jpg

# Crop profile photo centered under 200KB
python -m antigravity_bridge.cli --sanitize-photo ./docs/raw_photo.jpg

# Compress PDF to strictly under 1MB
python -m antigravity_bridge.cli --sanitize-pdf ./docs/heavy_architecture_spec.pdf
```

## Integration with Agentic AI Assistants

To make this bridge part of your assistant's autonomous behavior (e.g. in Antigravity IDE, Cursor rules, or Claude instructions), add the following protocol to your workspace rules:

```markdown
### Cloud Buffer & Out-of-Desk Protocol

1. Whenever the user is away or mentions Telegram, inspect `inbox/inbox_ledger.json` for new buffered items.
2. If an ingested item caption ends with `- now`, execute the request with highest priority and dispatch the answer via `send_telegram_file` or `send_telegram_text`.
3. Whenever generating or editing any document, PDF, presentation, or sanitized image, automatically dispatch the finished artifact to Telegram chat using the bridge.
```
